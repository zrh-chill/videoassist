# 视频转写与总结应用产品需求文档

## 1 产品概述

本产品是一款个人使用的 Web 应用，用于将本地视频或 B 站视频转换为完整文稿，并使用语言模型生成结构化总结。

首版目标是跑通以下两个核心场景：

- 处理单个本地视频或 B 站视频。
- 追踪 B 站 UP 主并处理其最新视频。

系统需要统一记录视频来源、处理状态、完整文稿、AI 总结、处理耗时和错误信息，方便后续查看、筛选与导出。

## 2 产品目标

- 支持上传本地视频。
- 支持通过 B 站视频链接创建处理任务。
- 使用 FFmpeg 从视频中提取音频。
- 使用语音转文字模型生成完整文稿。
- 使用语言模型生成结构化总结。
- 支持添加 B 站 UP 主，并获取其最新 N 条视频进行处理。
- 使用关系型数据库保存数据，并支持导出 Excel。
- 支持查看处理进度、失败原因和重新处理。

## 3 首版范围

### 3.1 首版包含

- 本地视频上传。
- B 站视频链接解析与下载。
- B 站 UP 主追踪。
- FFmpeg 音频提取。
- S2T 全文转写。
- AI 结构化总结。
- 视频列表与详情页。
- 处理进度、错误记录与失败重试。
- 系统配置与总结提示词配置。
- Excel 数据导出。

### 3.2 首版不包含

- B 站以外的视频平台。
- 多人账户、团队协作和权限管理。
- 人工字幕校对和视频剪辑。
- 跨视频知识库、向量搜索和智能问答。
- 移动端原生应用。

## 4 核心处理流程

1. 用户上传本地视频、输入 B 站视频链接，或从已追踪 UP 主中发现新视频。
2. 系统创建视频记录，并检查视频是否已经存在。
3. 系统读取本地视频或下载 B 站视频。
4. 系统使用 FFmpeg 提取统一格式的音频。
5. 系统调用 S2T 模型生成完整文稿。
6. 系统调用语言模型生成结构化总结。
7. 系统保存处理结果、耗时和日志。
8. 用户在视频列表或详情页查看结果，必要时重新处理。

## 5 功能需求

### 5.1 视频任务创建

#### 本地视频

- 用户选择本地视频文件并上传。
- 系统记录文件名、文件大小、视频时长和创建时间。
- 上传完成后自动创建处理任务。

#### B 站视频链接

- 用户粘贴 B 站视频链接。
- 系统识别链接并获取标题、BVID、UP 主、发布时间、封面和时长等信息。
- 系统根据 BVID 判断视频是否已经存在，避免重复处理。
- 解析成功后自动创建处理任务。

### 5.2 视频获取

- 本地视频直接使用上传后的文件。
- B 站视频使用对应的下载处理方式获取。
- 下载过程中显示当前状态。
- 下载失败时保存失败原因，并允许用户重试。
- 原始视频可以根据系统配置决定是否长期保留。

### 5.3 音频提取

- 使用 FFmpeg 从视频中提取音频。
- 将音频转换为 S2T 模型支持的统一格式。
- 保存处理状态、开始时间、结束时间和耗时。
- 提取失败时记录 FFmpeg 错误信息并支持重试。

### 5.4 全文转写

- 调用配置的 S2T 模型将音频转换为文本。
- 首版主要输出完整文稿。
- 建议同时保存带起止时间的分段文本，为后续字幕定位预留能力。
- 保存使用的模型、识别语言、处理耗时和创建时间。
- 转写失败时允许从转写阶段重新执行。

### 5.5 AI 总结

- 将完整文稿发送给配置的语言模型。
- 默认生成以下结构化内容：
  - 一句话摘要。
  - 核心要点。
  - 详细总结。
  - 关键词。
- 保存实际使用的语言模型和提示词版本。
- 文稿过长时，支持先分段总结，再生成整体总结。
- 用户可以使用当前系统配置重新生成总结。

### 5.6 B 站 UP 主追踪

- 用户通过 UP 主主页链接或 UID 添加追踪对象。
- 系统保存 UP 主昵称、UID 和主页链接。
- 用户可以设置每次获取最新 N 条视频，默认值建议为 5。
- 用户可以点击“立即检查”获取最新视频。
- 系统根据 BVID 与已有数据去重。
- 发现新视频后自动创建处理任务。
- 用户可以选择是否自动处理新发现的视频。
- 系统记录上次检查时间、新增视频数量和失败原因。

首版可以只支持手动检查更新，后续版本再增加定时检查。

### 5.7 视频结果管理

视频列表一行对应一条视频数据，主要展示：

| 字段 | 说明 |
| --- | --- |
| 状态 | 当前处理阶段或失败状态 |
| 标题 | 视频标题或本地文件名 |
| 来源 | 本地视频或 B 站 |
| UP 主 | B 站视频的发布者 |
| 发布时间 | B 站视频发布时间 |
| 创建时间 | 任务创建时间 |
| 文稿状态 | 未生成、已生成或失败 |
| 总结状态 | 未生成、已生成或失败 |
| 错误摘要 | 最近一次失败原因 |

列表支持：

- 按标题搜索。
- 按来源和处理状态筛选。
- 打开视频详情。
- 对失败任务执行重试。
- 导出当前筛选结果。

### 5.8 视频详情

详情页展示：

- 视频基础信息。
- 原始链接或本地文件信息。
- 当前处理状态和各阶段耗时。
- 完整文稿。
- AI 总结。
- 处理日志和错误详情。

详情页支持：

- 复制完整文稿或总结。
- 重新下载 B 站视频。
- 重新提取音频。
- 重新转写。
- 重新生成总结。

### 5.9 数据导出

- 将筛选后的视频数据导出为 Excel。
- 每条视频对应 Excel 中的一行。
- 导出内容包括视频基础信息、处理状态、完整文稿和总结字段。
- 过程日志默认不放入主表，可根据需要增加单独工作表。

### 5.10 系统配置

系统配置包括：

- FFmpeg 可执行文件路径。
- S2T 模型、接口地址、密钥和基础参数。
- 语言模型、接口地址、密钥和基础参数。
- 总结系统提示词。
- 长文稿切片参数。
- 视频、音频和结果文件的保存目录。
- B 站下载相关配置。

密钥只保存引用或加密后的值，不在页面、日志和导出文件中直接展示。

## 6 页面结构

| 页面 | 主要内容 | 主要操作 |
| --- | --- | --- |
| 视频列表 | 所有视频及处理状态 | 搜索、筛选、查看、重试、导出 |
| 添加视频 | 本地上传区和 B 站链接输入框 | 上传、解析、创建任务 |
| 视频详情 | 视频信息、文稿、总结和日志 | 复制、重新处理 |
| UP 主追踪 | UP 主列表和检查结果 | 添加、编辑、删除、立即检查 |
| 系统设置 | 模型、提示词和存储配置 | 保存配置、测试连接 |

## 7 处理状态

| 状态 | 说明 |
| --- | --- |
| 等待处理 | 任务已创建，等待执行 |
| 获取视频中 | 正在读取本地文件或下载 B 站视频 |
| 提取音频中 | 正在执行 FFmpeg |
| 转写中 | 正在调用 S2T 模型 |
| 总结中 | 正在调用语言模型 |
| 已完成 | 完整文稿和总结均已生成 |
| 处理失败 | 任一阶段执行失败 |
| 已取消 | 用户主动取消任务 |

每个阶段应记录开始时间、结束时间、处理结果和错误信息。任务失败后，用户可以从失败阶段重新执行，不需要重复已经成功的步骤。

## 8 数据记录

数据库作为主存储，Excel 作为导出格式。

### 8.1 视频记录

- 来源类型。
- BVID。
- 原始链接。
- 本地文件路径。
- 标题、UP 主和发布时间。
- 视频时长和封面。
- 当前处理状态。
- 最近一次错误信息。
- 创建时间和更新时间。

### 8.2 转写记录

- 关联视频 ID。
- 完整文稿。
- 带时间信息的分段文本。
- S2T 模型和语言。
- 处理耗时。
- 创建时间。

### 8.3 总结记录

- 关联视频 ID。
- 一句话摘要。
- 核心要点。
- 详细总结。
- 关键词。
- 语言模型。
- 提示词版本。
- 创建时间。

### 8.4 UP 主记录

- UID、昵称和主页链接。
- 每次获取的最新视频数量。
- 是否自动处理。
- 上次检查时间和检查结果。

### 8.5 执行日志

- 关联视频 ID。
- 处理阶段。
- 开始时间和结束时间。
- 执行状态。
- 错误详情。

## 9 非功能要求

- 首版面向个人使用，可以暂不提供用户登录功能。
- 页面刷新或应用重启后，任务状态和历史结果仍可恢复。
- 单个处理阶段失败时，不丢失此前已经完成的数据。
- 下载、转写和总结操作需要避免重复执行。
- 接口密钥等敏感信息不得写入普通日志。
- B 站内容获取功能应遵守平台规则；登录态失效、请求限流或链接失效时，应向用户展示明确提示。

## 10 首版验收标准

- 能够上传一个本地视频并生成完整文稿与结构化总结。
- 能够输入一个有效的 B 站视频链接并完成下载、转写和总结。
- 相同 BVID 重复导入时不会产生重复视频记录。
- 能够添加一个 B 站 UP 主，获取其最新 N 条视频并为新增视频创建任务。
- 能够在列表中查看全部视频的当前状态。
- 能够在详情页查看完整文稿、总结和错误日志。
- 转写或总结失败后可以重试，并在成功后正确更新结果。
- 能够将筛选后的视频记录、文稿和总结导出为 Excel。
- 能够修改总结提示词，并使用新提示词重新生成总结。

## 11 建议实施顺序

1. 完成视频任务、数据库和处理状态基础能力。
2. 接入本地视频、FFmpeg、S2T 和语言模型，跑通单条视频处理流程。
3. 接入 B 站视频解析、下载和 BVID 去重。
4. 实现视频列表、详情页、失败重试和 Excel 导出。
5. 实现 UP 主追踪、最新 N 条检查和自动创建任务。
6. 补充系统配置、提示词版本和长文稿分段总结。
